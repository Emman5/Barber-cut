# Fresh Cuts — Barber Shop Landing Page

A single-page site for a barber shop: services, gallery, hours, and contact.

**Live:** https://emman5.github.io/Barber-cut/

## What's here

- **Services** — Precision Fades, Loc Maintenance, and Afro Shaping, each with
  its own card
- **Gallery** — grid of previous cuts
- **Hours and contact** — the two things people actually open a barber's site for,
  kept above the fold on mobile
- **Responsive nav** — hamburger menu with a staggered link-fade animation,
  hand-written rather than pulled from a framework

## Stack

Vanilla HTML, CSS, and JavaScript. No dependencies, no build step. Deployed on
GitHub Pages.

## Status

Front-end only — this is a design and layout exercise, not a booking system.
There's no backend and no scheduling integration.

For the same idea taken all the way to a working client site — with booking,
payments, a service-area map, and a live Instagram feed — see
[H-details](https://github.com/Emman5/H-details).
